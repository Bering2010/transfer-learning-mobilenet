# Transfer Learning com MobileNetV2

Este projeto aplica Transfer Learning para classificar imagens de gatos e cachorros utilizando a arquitetura MobileNetV2, pré-treinada com o conjunto ImageNet.

O desenvolvimento foi realizado em Python no Google Colab, utilizando TensorFlow e Keras. O projeto inclui preparação das imagens, normalização, treinamento, validação e análise dos gráficos de acurácia e perda.

## Tecnologias utilizadas

- Python
- TensorFlow
- Keras
- MobileNetV2
- Google Colab
- Matplotlib
